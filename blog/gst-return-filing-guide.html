GST Return Filing: GSTR-1, GSTR-3B, GSTR-9 की पूरी Guide 2025

📅 January 2025  |  ⏱ 9 min read  |  ✍ Digital Seva Center

GST (Goods and Services Tax) India में 2017 से लागू है और हर registered business को समय पर GST Return file करना अनिवार्य है। GSTR-1, GSTR-3B, और GSTR-9 — इन तीनों returns की अलग-अलग due dates, process और penalties हैं। इस guide में सब कुछ clearly समझाया गया है।

GST Return क्या होता है?

GST Return एक official document है जिसमें आप government को बताते हैं कि आपने कितनी sales की, कितना tax collect किया, और कितना tax pay करना है। यह Income Tax Return की तरह होता है, लेकिन GST के लिए।

India में different types के taxpayers के लिए different returns होते हैं। Regular taxpayers को mainly तीन returns file करने होते हैं:

  • GSTR-1: Outward supplies (आपकी sales) की details
  • GSTR-3B: Monthly summary return और tax payment
  • GSTR-9: Annual return (साल का पूरा हिसाब)

GSTR-1: Outward Supply Return

GSTR-1 में आप अपनी outward supplies यानी sales की details भरते हैं। इसमें B2B invoices, B2C sales, exports, credit notes सब include होते हैं।

GSTR-1 में क्या भरते हैं?

  • Table 4A/4B: B2B supplies (GST registered customers को बेचा)
  • Table 5: B2C large (₹2.5 लाख से ज़्यादा, inter-state)
  • Table 6: Exports

  • Table 9: Amendments to earlier returns

💡 Pro Tip: GSTR-1 file करने के बाद आपके buyers को GSTR-2B में automatically आपकी invoices दिखती हैं। इसलिए invoices सही और समय पर upload करें — इससे buyers का ITC claim होता है।

GSTR-3B: Monthly Summary Return

GSTR-3B एक self-declaration return है जिसमें आप अपनी total sales, total purchases, ITC claim, और net tax liability summary में भरते हैं। यह return और tax payment एक साथ होती है।

GSTR-3B Step-by-Step Process

  1. 1 GST Portal (gst.gov.in) पर login करें
  2. 2 Returns Dashboard खोलें → GSTR-3B select करें
  3. 3 Tax period choose करें (month/quarter)
  4. 4 Table 3.1: Outward supplies (IGST, CGST, SGST)
  5. 5 Table 4: ITC available और reversals
  6. 6 Net tax liability calculate होगी automatically
  7. 7 Challan generate करें और payment करें
  8. 8 DSC या EVC से file करें
⚠️ Important: GSTR-3B file करने से पहले GSTR-2B ज़रूर check करें — इससे आपको पता चलेगा कि आपके suppliers ने कितना ITC upload किया है। गलत ITC claim करने पर interest और penalty हो सकती है।

ITC (Input Tax Credit) क्या होता है और कैसे Claim करें?

ITC यानी Input Tax Credit — जो tax आपने अपनी purchases पर pay किया, वो आप अपनी sales के tax में से minus कर सकते हैं। इससे double taxation से बचाव होता है।

ITC Claim के लिए Conditions

  • Supplier ने GSTR-1 में invoice upload की हो
  • आपके पास valid tax invoice हो
  • Goods या services receive हो चुकी हों
  • Tax actually pay हो चुका हो supplier द्वारा
  • आपने GSTR-3B file की हो

GSTR-9: Annual Return

GSTR-9 हर financial year के बाद file करनी होती है। इसमें पूरे साल की supplies, purchases, ITC, और tax liability का consolidated summary होता है।

GSTR-9 Due Date और Exemption

Annual TurnoverGSTR-9 FilingDue Date

💡 Note: ₹2 crore तक turnover वाले businesses के लिए GSTR-9 optional है, लेकिन file करना recommended है — इससे आपका GST record clean रहता है और future में bank loans, tenders में help होती है।

GST Late Fee और Penalty

अगर GST return time पर file नहीं की, तो late fee लगती है। यह automatically calculate होती है और next return में pay करनी पड़ती है।

GST Return File करने से पहले यह Checklist Follow करें

  • ✅ सभी sales invoices GST Portal पर upload हों
  • ✅ GSTR-2B में ITC properly reflect हो
  • ✅ E-way bills reconcile हों
  • ✅ Bank statements से sales match करें
  • ✅ Previous month की returns filed हों
  • ✅ Electronic Cash Ledger में sufficient balance हो
  • ✅ DSC/EVC login ready हो

Common GST Return Mistakes जो Notice का कारण बनती हैं

  1. GSTR-1 और GSTR-3B mismatch: GSTR-1 में ज़्यादा और 3B में कम दिखाना
  2. Excess ITC claim: GSTR-2B से ज़्यादा ITC claim करना
  3. Wrong HSN code: Products के लिए गलत HSN code use करना
  4. Missing B2B invoices: Registered buyers की invoices upload न करना
  5. Late filing consistently: हर महीने late fee देना और notice आना

GST Notice आने पर क्या करें?

अगर आपको GST Department से कोई notice आया है, तो घबराएं नहीं। Notice types:

  • ASMT-10: Return scrutiny — reply 30 दिन में देनी है
  • DRC-01: Tax demand — 30 दिन में payment या response
  • REG-17: Registration cancellation notice

किसी भी GST notice के लिए तुरंत expert से consult करें। Reply में देरी करने पर ex-parte order pass हो सकता है।

Conclusion

GST Return filing एक ongoing compliance है। GSTR-1, GSTR-3B, और GSTR-9 — तीनों को समय पर file करने से आपका business legally compliant रहता है, ITC का full benefit मिलता है, और government से कोई notice नहीं आता।
